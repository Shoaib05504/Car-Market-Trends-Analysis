# Car Market Trends Analysis with Car Dekho Data

## Project Overview

Car Market Trends Analysis is a data analytics project based on the Car Dekho used-car dataset. The project uses Python to load, clean, transform, and analyze the data to identify important patterns and trends in the used-car market.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Project Features

- Data loading and cleaning
- Data transformation and preprocessing
- Creation of a Car Age feature from manufacturing year
- Fuel type analysis
- Selling price analysis
- Car age vs selling price analysis
- Statistical analysis using mean and median
- Correlation analysis using a heatmap
- Data visualization using different charts

## Analysis Performed

The project analyzes important factors including:

- Selling Price
- Present Price
- Kilometers Driven
- Car Age
- Fuel Type
- Seller Type
- Transmission
- Ownership
- Car Models

Different visualizations such as bar charts, pie charts, scatter plots, histograms, box plots, and correlation heatmaps are used to identify price patterns, relationships, distributions, and market trends.

## Dataset

The project uses the Car Dekho used-car dataset.

## Repository Contents

- `Car_Market_Trends_Analysis.ipynb` – Complete data analysis notebook
- `Car Market Trends Analysis with Car Dekho Data.csv` – Dataset used for analysis

## Conclusion

This project converts raw used-car market data into meaningful insights about car pricing, vehicle characteristics, and overall market behavior.
